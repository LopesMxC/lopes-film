# Economy: input

Everything read is paid for again on every later turn.

- List, then open: names, counts, `grep -n` first; then one range.
- Read what the edit needs (exact text around it); read once, reread only if it changed.
- Output of any command: `tail -n 30` / `head -n 40` / a filter. Filter long logs.
- Media: read its facts (duration, size, transcript); look at frames only as the judgement needs.
- Never paste a file or a result back into a reply: point to it by name and line.

Never economize on checking the result.
