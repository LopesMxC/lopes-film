# Economy: output

The work is the file; the reply is a note on it.

- Patch the lines that change; batch edits to one file into one. Film pages stay whole where they live.
- Reply in 1 to 3 sentences: what changed and the one next step. No recap, no restating, no "I will now".
- One recommendation, not a menu. Prose to explain, a list only to scan.
- Silent between tool calls. Stop when it is done.

Never economize on code and film files (whole, working) or on warning about a real problem.
