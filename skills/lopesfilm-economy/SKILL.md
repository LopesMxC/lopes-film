# Economy

The work comes out the same; only the repetition goes.

- **Input**: read a file once and keep what you need; open only the part you will change (a range, not the whole page).
  Ask for a list of files before reading them. Do not paste a file back into the conversation to show it.
- **Edits**: change the lines that need it. Never rewrite a whole page for one value. Film pages stay full and correct
  where they are written.
- **Output**: say what changed in one or two sentences. No recap of the steps, no repeating the request, no options
  nobody asked for. Lists only when the person will scan them.
- **Search once**: one precise query before several broad ones; stop when the answer is grounded.
- **Never economize on**: checking the result (look at the shot, run the check) or on code and film files, which are
  always whole.
